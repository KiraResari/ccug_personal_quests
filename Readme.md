# GCUG Gloomhaven/Frosthaven Extra Class Personal Quests

These are custom personal quests for the extra Gloomhaven/Frosthaven from the Gloomhaven Content Creators Unity Guild. You can find those extra classes here:

https://drive.google.com/drive/folders/15K9hIrRzkVRbhF5Bj4KOGNE-TtvmYxcq

## Recommended Use

* If you're playing the original Gloomhaven, you can just combine these Personal Quests with the original Personal Quests at your own discretion
* If you're playing Frosthaven or Gloomhaven 2nd edition then I recommend only adding these Personal Quests once you've unlocked everything
